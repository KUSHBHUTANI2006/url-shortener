# url-shortener
A URL shortener built with Python, Flask and SQLite

## features 
- Shorten any long url to a custom short link and redirects short link to original url
- Prevents duplicate short link
- Can use to find original link from the short link if the user had earlier created a short url   from the website
- Light and Dark mode
- Built with  FLASK BACKEND and SQLITE DATABSE

## tech stack
- Python
- Flask
- SQLite
- HTML/CSS

## How to Run

1. Clone the repository
   git clone https://github.com/KUSHBHUTANI2006/url-shortener.git

2. Install dependencies
   pip install flask

3. Run the app
   python app.py

4. Open browser and go to
   http://127.0.0.1:5000
